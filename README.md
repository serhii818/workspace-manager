## About project
A python based tool for launching several applications and programs for work.

It's a personal tool that I use to launch different editors and software with specified files or folders to work on my projects.

## How to run
To run this project you need to have python installed.

You can run program directly by running wsmgr.py script.
Type wsmgr -h to print help manual

The repository also has a c++ wrapper wsmgr.cpp that launches python script and passes all arguments to the script automatically. This is done for convenience if you want a clean cli tool.
